Configurar la edición del sitio

Esta página genera el archivo edicion.json. Todo se procesa en este navegador: la llave de GitHub, el usuario y la contraseña no se envían a ningún lado. El archivo resultante guarda la llave cifrada, y solo se abre con el usuario y la contraseña que elijas.

Acceso para editar

Subí edicion.json a la raíz del repositorio, junto a index.html. Cuando la llave venza, repetí estos pasos con una llave nueva.
